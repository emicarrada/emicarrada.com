# Aquí irán las imágenes de tu blog personal

## Imágenes que necesitarás:

### Para cada artículo:
1. **Imagen de portada**: 400x600px - aparece en la tarjeta del carrusel
2. **Imágenes de contenido**: Ancho variable - aparecen dentro del artículo

### Convenciones de nombres:
- Portadas: `portada-[nombre-articulo].jpg`
- Contenido: `[nombre-descriptivo].jpg`

### Ejemplos:
- `portada-mi-primer-startup.jpg`
- `contenido-oficina-desarrollo.jpg`
- `portada-reflexiones-code.jpg`
